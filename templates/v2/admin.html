A bot that sends each person who clicks Connect Discord a private DM. {{ discord_connected }} connected. People can also post to their own channel with a webhook, which needs nothing here.

Set up Discord DMs (once)
  1. In the Discord Developer Portal ↗, create an application. Copy its Application ID and, under OAuth2, its Client secret.
  2. Under OAuth2 → Redirects, add exactly: {{ discord_redirect }}
  3. Under Bot, reset and copy the bot token. It needs no privileged intents.
  4. Make a private Discord server for Wealtharr. With Developer Mode on, right-click it and copy its Server ID.

Telegram

{% if telegram_bot %}Set up · @{{ telegram_bot }}{% else %}Not set up{% endif %}

A bot that messages each person who clicks Connect Telegram in Alerts & settings. {{ telegram_connected }} connected. It needs no public web address, so a private site works.

Set up Telegram (once)
  1. In Telegram, open @BotFather ↗ and send /newbot. Pick a name and a username ending in "bot".
  2. Copy the token it gives you (it looks like 123456:ABC…), paste it below and save. Wealtharr checks it with Telegram and stores it encrypted.
  3. Don't add a webhook to the bot: Wealtharr reads its messages directly.
