A bot that messages each person who clicks Connect Telegram in Alerts & settings. {{ telegram_connected }} connected. It needs no public web address, so a private site works.

Set up Telegram (once)
  1. In Telegram, open @BotFather ↗ and send /newbot. Pick a name and a username ending in "bot".
  2. Copy the token it gives you (it looks like 123456:ABC…), paste it below and save. Wealtharr checks it with Telegram and stores it encrypted.
  3. Don't add a webhook to the bot: Wealtharr reads its messages directly.
